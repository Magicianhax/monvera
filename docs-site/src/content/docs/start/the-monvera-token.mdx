Investing with Vera is free of any token toll. $MONVERA is how you back the agent, not how you unlock her. It isn't an investment product, and its price can go down as well as up.

## What the token is for

Vera is a working agent: she routes real volume through a live venue, records a signed risk assessment for every plan, and sells portfolio-plan building to other agents on Virtuals ACP. $MONVERA is the community's way to back that agent inside the Virtuals agent economy.

What that means today: a stake in the agent, on the same chain as the product, with fixed supply and locked tokenomics. Where it can go — paying for Vera's agent-to-agent work, early access to new capabilities, community input on strategies — follows the same standard as [our roadmap](https://monvera.best/roadmap): we say *exploring* until it ships.
