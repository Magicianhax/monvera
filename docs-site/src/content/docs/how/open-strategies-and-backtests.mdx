Monvera's strategies are rule-based, and each one carries a walk-forward backtest with its assumptions stated. The raw numbers are public at `/api/strategies`, so you can read the rule and its history rather than take a chart on faith.

## Rule-based, not discretionary

Each strategy is a fixed rule over the 95-asset universe, not a per-day human call. Because the rule is fixed, its history can be replayed the same way every time, which is what makes a backtest meaningful here. The strategies live at [monvera.best/strategies](https://monvera.best/strategies), and the machine-readable version is `/api/strategies`.

## What walk-forward means, and its limits

A walk-forward backtest applies the rule forward through time, using only the price history available up to each point, then measures what the rule would have done next. That avoids scoring a rule on data it would not have had at decision time. Each backtest ships with its assumptions so you can see what it did and did not account for.

<Aside type="caution">
A backtest is history, not a promise. It shows what a rule did on past prices, and past prices do not predict future ones. See [backtests are history, not promises](/safety/backtests-are-history-not-promises/).
</Aside>

## Read the strategies and run a backtest

`/api/strategies` returns the strategies with their backtests, and `POST /api/backtest` runs a walk-forward backtest for a strategy rule. Both are public (no token).

<Tabs>
<TabItem label="curl">

```bash
# The open strategies with their backtests (public GET)
curl "https://monvera.best/api/strategies"

# A walk-forward backtest for a strategy rule (public POST)
curl -X POST "https://monvera.best/api/backtest" \
  -H "Content-Type: application/json" \
  -d '{"strategy":"steady-growth"}'
```

</TabItem>
<TabItem label="fetch">

```js
// The open strategies with their backtests (public GET)
const strategies = await (
  await fetch("https://monvera.best/api/strategies")
).json();

// A walk-forward backtest for a strategy rule (public POST)
const backtest = await (
  await fetch("https://monvera.best/api/backtest", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ strategy: "steady-growth" }),
  })
).json();
```

</TabItem>
</Tabs>

`/api/strategies` is rate limited to 30 requests per 60 seconds per IP, and `/api/backtest` to 20 requests per 60 seconds per IP. A caller over the limit gets `429` with `{"error":"Too many requests. Please slow down a moment."}` and a `Retry-After` header.

## Theme baskets

The same engine also builds one basket per investing theme: Artificial Intelligence, Semiconductors, Quantum, Space, Crypto-linked stocks, Cloud and Software, Energy, and Fintech. Each theme takes its curated universe, weights every name inversely to its volatility with a 25% cap, and gets the same walk-forward backtest against the S&P 500. Names without a year of public history are excluded and listed by name on the page, because we name exclusions instead of inventing data for them.

<img src="/screens/themes-index.webp" alt="The theme baskets index: eight cards, each with its six-month walk-forward result against the S&P 500 and its allocation bar" />

Browse them at [monvera.best/themes](https://monvera.best/themes), or pull the raw JSON from [`/api/themes`](/dev/api/themes/) (public, no auth, 120 requests per 60 seconds per IP). Every theme page shows the full rule so you can reproduce the weights yourself.
