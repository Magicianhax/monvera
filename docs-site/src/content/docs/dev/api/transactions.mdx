<Badge text="GET" variant="tip" /> <Badge text="Public" variant="note" /> `https://monvera.best/api/transactions`

GET the incoming and outgoing token transfers for any account address, newest first, up to 50. Transfers are labeled with Monvera's symbols (USDG, AAPL, NVDA) when the token is in the catalog. Public chain data, no token. Rate limited to 30 requests per 60 seconds per IP.

The response names which indexed source served it in a `source` field: Alchemy when an `ALCHEMY_API_KEY` is configured, otherwise the keyless Blockscout fallback. Both read the same on-chain transfers.

## What it returns

A `transactions` array (newest first, deduped, capped at 50) and a `source` string. Direction is relative to the queried account: `"out"` means the account sent, `"in"` means it received.

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `address` | address | yes | none | The account whose transfers to read. A missing or invalid address returns 400. |

## Returns

| Field | Type | Description |
| --- | --- | --- |
| `transactions` | array | Transfers, newest first, up to 50. |
| `transactions[].hash` | bytes32 | Transaction hash. Open it on Blockscout. |
| `transactions[].direction` | string | `"in"` or `"out"`, relative to the queried account. |
| `transactions[].symbol` | string | Catalog symbol when known, else the on-chain asset symbol. |
| `transactions[].amount` | number | Human amount moved. |
| `transactions[].counterparty` | string | The other party (recipient if out, sender if in). |
| `transactions[].tokenAddress` | string | Token contract address. |
| `transactions[].blockNumber` | number | Block the transfer landed in. |
| `transactions[].timestamp` | number \| undefined | Unix seconds, when resolvable. |
| `source` | string | `"alchemy"` or `"blockscout"`. |

## Example request

## Failure paths

- A missing or invalid `address` returns 400 `{"error":"A valid wallet address is required."}`.
- Over 30 requests in 60 seconds from one IP returns 429 `{"error":"Too many requests. Please slow down a moment."}` with a `Retry-After` header.
- An account with no transfers, or an upstream that returns nothing, yields an empty `transactions` array with the `source` still set.
