`GET /api/screener` returns every buyable asset with four real figures computed from 12 months of price history, so you can rank them instead of guessing. Assets with no honest public history are dropped from the response, never ranked on a faked series.

- **Method and path**: `GET https://monvera.best/api/screener`
- **Auth**: none (public)
- **Rate limit**: 60 requests per 60 seconds per IP

The screener shares its cached computation with Vera's allocation prompt, so a page of clients costs at most one upstream build per window.

## Parameters

This route takes no parameters. It returns the whole buyable set.

## Returns

`{ assets, asOf }`.

`assets` is an array of stat rows, one per buyable asset that has usable history:

| Column | Type | Description |
| --- | --- | --- |
| `symbol` | string | The asset ticker, for example `NVDA`. |
| `ret1yPct` | number \| null | Total return over the last ~12 months, percent. |
| `ret3mPct` | number \| null | Return over the last ~3 months, percent. `null` when history is too short. |
| `volPct` | number | Annualized daily volatility, percent. |
| `maxDrawdownPct` | number | Worst peak-to-trough drop over the period, percent (a positive number). |
| `noData` | boolean | Always `false` in the response. |

`asOf` is the ISO timestamp of the response.

<Aside type="note" title="No-data rows are excluded, not returned">
The stat layer marks assets with no honest public series as `noData: true`, and this route filters those out before responding. So every row you receive has real figures, and `noData` is always `false`. The total row count is therefore the buyable assets that have usable history, which can be fewer than the full 95 assets on a given day. See [Use the screener](/use/use-the-screener/).
</Aside>

## Example request

<Tabs>
<TabItem label="curl">

```bash
curl "https://monvera.best/api/screener"
```

</TabItem>
<TabItem label="fetch">

```javascript
const { assets } = await fetch(
  "https://monvera.best/api/screener",
).then((r) => r.json());

// Sort by one-year return, highest first
const ranked = [...assets].sort((a, b) => (b.ret1yPct ?? 0) - (a.ret1yPct ?? 0));
```

</TabItem>
</Tabs>
