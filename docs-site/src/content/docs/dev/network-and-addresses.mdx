Every chain value and contract address Monvera uses is on this page, each linked to Blockscout. Take addresses from here, never from a tweet or a screenshot.

## Robinhood Chain network values

Monvera settles on Robinhood Chain, an Arbitrum-stack Ethereum L2. The native gas token is ETH (18 decimals).

| Value | Mainnet | Testnet |
| --- | --- | --- |
| Chain id | `4663` | `46630` |
| RPC | `https://rpc.mainnet.chain.robinhood.com` | `https://rpc.testnet.chain.robinhood.com` |
| Explorer (Blockscout) | `https://robinhoodchain.blockscout.com` | `https://explorer.testnet.chain.robinhood.com` |

<Aside type="note">
Public RPC caps `eth_getLogs` at 10,000 blocks per request. The Monvera record scanner chunks at 9,999 blocks and starts at deploy block `2429508`. For full record history without paging logs yourself, use [`/api/vera-record`](/dev/api/vera-record/).
</Aside>

## Vera's canonical identity (Base, chain 8453)

Vera's canonical ERC-8004 identity lives on Base, not on 4663. The registry is [`0x8004a169fb4a3325136eb29fa0ceb6d2e539a432`](https://basescan.org/address/0x8004a169fb4a3325136eb29fa0ceb6d2e539a432) on chain `8453`, agent id `58228`, registered via Virtuals ACP. It is declared in `registrations[0]` of her [agent card](/dev/verify-vera/#what-the-agent-card-declares). The 4663 IdentityRegistry above is Monvera's own registry and holds Vera as agent #1; do not label it "canonical."

## The trusted agent signer

`agentSigner()` on VeraRecord was last read as `0xe532105523d4eD559c3a53E3E82D616bE1a085c5`. This key can rotate, so read it live before you assert against a recovered signature rather than hardcoding it. The recovery recipe is on [Verify Vera yourself](/dev/verify-vera/#recover-the-signer-and-check-it).
